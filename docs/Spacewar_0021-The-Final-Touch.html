9.7 Spacewar! The Final Touch ¶

At this position of the book, you have already written a fair amount of the code of the Spacewar! game. However, it is very likely there are missing peaces in your code or you may have inconsistency against the final source code of the game. Let’s take this as an opportunity to introduce tools to compare the code installed in the Cuis-Smalltalk image and the code from a file, as a plain .st fileout or a .pck.st package file.

First, you need to get the complete package of the Spacewar! game found in the appendix; then, invoke the Cuis-Smalltalk File List tool ...World menu → Open → File List, and search for the file package Spacewar!.pck.st you just downloaded.

Figure 9.14: File List on Spacewar! package

The File List tool has a pck contents button to examine its contents against the image code. Press this button, its opens in a new window the Package contents tool.

On the top, it displays the type of content which are:

  • do it. Code snippet executed at the package installation, for example to create new class or method categories defined in the package.
  • class definition. Change in a class definition: attributes and parent class.
  • class comment.
  • method. Change in a method source code or new method.

Figure 9.15: Package contents

By default, the tool shows all the contents of the package, without considering the difference with code installed in the image. To only show the differences, adjust the tool from its contextual menu to remove unnecessary information: Remove doIts and Remove up-to-date versions. Once you have narrow the list of changes to what you need, select all then file in selections to install these changes in the image.

Figure 9.16: A selection of changes to file in

You will get installed with the missing and changed parts of the game. To start it, select and execute SpaceWar new openInWorld in a Workspace.
